# Smart Hospital Patient & Resource Allocation System


This is a C programming project developed to manage basic hospital patient and resource information.

The system allows users to register patients, manage specialties and wards, calculate bills, check bed status, generate reports, and save patient information.

## Main Features

- Patient registration
- Doctor specialty information
- Hospital ward information
- Bed status
- Waiting-time calculation
- Emergency surcharge calculation
- Ward stay cost calculation
- Patient billing
- Age-based subsidy
- Patient priority display
- Hospital reports
- File handling

## Project Files

- `main.c` - Main program and menu
- `hospital.c` - Hospital system functions
- `hospital.h` - Function declarations
- `SmartHospital.cbp` - Code::Blocks project file
- `patient_records.txt` - Saved patient records
- `beds_status.txt` - Saved bed status

## How to Run

1.Download zip file and extract the zip file.
2. Open `SmartHospital.cbp` in Code::Blocks.
3. Build the project.
4. Run the program.
5. Select an option from the main menu.
